# 核心世界规则

## 多元大世界
每一个世界都表现为一个封闭的圆形空间区域。
其本质是独立拓扑结构，具有明确边界。
在世界边界之外，并不存在其他连续空间，而是进入一种被定义为“无空间状态”的区域——空间维度在此失效，不具备距离与方向的意义。
世界数量目前无法确认，整体结构呈现非穷尽性。

## 世界之间的连接机制
虽然世界彼此独立，但并非完全隔绝。
世界之间可以通过特定机制建立连接，这种连接被称为：“桥梁（Bridge）”

桥梁的性质如下：

并非自然普遍存在
需要特定条件或力量生成
可连接不同世界（如：神界 ↔ 人界，人界 ↔ 魔界）
具有稳定性差异（永久 / 临时 / 单向）
桥梁是多元世界之间唯一已知的“结构性通道”。

## 创世界（四界结构 / 已建立桥梁状态）
创世界由三大基础世界 + 一个异常半界构成。
1. 神界（Divine Realm）
众神栖居之所，代表“规则制定层”。
神界并非单纯的居住空间，而是具备对多元世界进行规则干涉与秩序维护的高位结构。
2. 人界（Mortal Realm）
人类文明所在的基础现实世界。
人界是多元结构中最稳定、最普遍的世界层，也是各界力量交汇与冲突的核心区域。
3. 魔界（Demonic Realm）
恶魔及侵蚀性存在的聚集区域。
魔界属于高不稳定性世界结构，由掠夺、混乱与扩张性规则主导，与人界长期处于对抗与渗透关系。
4. 冥界（Underworld / 0.5异常区域）
冥界并非完整世界，而是一个系统性异常产物（BUG REGION）。
其本质是：
当灵能与意识在死亡或崩解后无法被神界回收、也无法在魔界消化时，系统“溢出”形成的残留空间。
因此冥界具备以下特性：
不属于标准三界结构
无完整世界规则（不具备独立生态闭环）
属于“半存在区域”（0.5世界）
主要功能：灵魂与灵能的滞留、堆积与延迟消散
常被称为“灵能无处可去的收容层”
