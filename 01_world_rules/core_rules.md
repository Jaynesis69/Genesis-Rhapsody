# 核心世界规则

## 多元大世界
每一个世界都表现为一个封闭的圆形空间区域。
其本质是独立拓扑结构，具有明确边界。
在世界边界之外，并不存在其他连续空间，而是进入一种被定义为“无空间状态”的区域——空间维度在此失效，不具备距离与方向的意义。
世界数量目前无法确认，整体结构呈现非穷尽性。

## 世界之间的连接机制
虽然世界彼此独立，但并非完全隔绝。
世界之间可以通过特定机制建立连接，这种连接被称为：“桥梁（Bridge）”

桥梁的性质如下：

并非自然普遍存在
需要特定条件或力量生成
可连接不同世界（如：神界 ↔ 人界，人界 ↔ 魔界）
具有稳定性差异（永久 / 临时 / 单向）
桥梁是多元世界之间唯一已知的“结构性通道”。
