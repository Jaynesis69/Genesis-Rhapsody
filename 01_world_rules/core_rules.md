# 核心世界规则

## 多元大世界
每一个世界都表现为一个封闭的圆形空间区域。
其本质是独立拓扑结构，具有明确边界。
在世界边界之外，并不存在其他连续空间，而是进入一种被定义为“无空间状态”的区域——空间维度在此失效，不具备距离与方向的意义。
世界数量目前无法确认，整体结构呈现非穷尽性。

## 世界之间的连接机制
虽然世界彼此独立，但并非完全隔绝。
世界之间可以通过特定机制建立连接，这种连接被称为：“桥梁（Bridge）”

桥梁的性质如下：

并非自然普遍存在
需要特定条件或力量生成
可连接不同世界（如：神界 ↔ 人界，人界 ↔ 魔界）
具有稳定性差异（永久 / 临时 / 单向）
桥梁是多元世界之间唯一已知的“结构性通道”。

## 创世界（4界结构 / 已建立桥梁状态）

创世界由三大基础世界 + 一个异常半界构成，并通过“桥梁结构”实现有限互通。

1. 神界（Divine Realm）

众神与天使的栖居之所，代表“规则制定层”。

神界呈现为一个永恒悬浮于高空的天空世界。
其空间结构稳定悬浮，不依附于行星或地面系统。

世界特征如下：

永无黑夜，恒定明亮的天空环境
云海与高空结构构成主要地貌
天使具备天然飞行能力，可在空间中自由移动
神族本质由“灵能体”构成，而非纯物质生命
神界是多元世界规则的制定与干涉中心
2. 人界（Mortal Realm）

人类文明所在的基础现实世界。

人界是四界中最“标准化”的世界形态，具备完整自然循环系统。

世界特征如下：

拥有太阳、月亮与星空系统
存在昼夜交替与稳定时间流动
生态结构完整（自然/生命/文明演化）
是神界、魔界与冥界力量交汇的核心区域
大部分历史与战争事件发生于此
3. 魔界（Demonic Realm）

恶魔及侵蚀性存在的聚集区域。

魔界呈现为一个持续崩坏与重构的地狱型世界，环境高度不稳定。

世界特征如下：

由火焰、熔岩、地震裂隙构成主要地貌
空间结构持续震荡与破裂
存在高频能量爆发与灾变现象
生态以掠夺、侵蚀与吞噬为核心逻辑
与人界长期处于冲突与渗透状态
4. 冥界（Underworld / 0.5异常区域）

冥界并非完整世界，而是系统性异常产物（BUG REGION），属于“半存在结构（0.5世界）”。

其本质是：

当灵能与意识在死亡或崩解后，既无法被神界回收，也无法被魔界消化时，系统发生“能量溢出”而形成的残留空间。

世界特征如下：

不具备完整世界生态闭环
属于半稳定异常空间
无统一白昼系统，整体呈“持续暗态”
充满灵能与能量风暴，闪电频繁发生
灵魂与灵能以不稳定形态漂浮、聚集与崩解
常被称为“灵能失衡之地”或“灵魂滞留层”
